## 1. 执行摘要

本蓝图采用长期使用、成本优先的方案：

- 打印机选型：**TSC TE344，300 dpi，4 英寸热转印，USB**。
- 扫码枪选型：**Newland HR22 系列或同级三模二维扫码枪**，日常使用 2.4G USB 接收器，以 USB HID 键盘方式接入。
- 硬件预算：打印机与扫码枪合计目标 **RMB 1,450–1,900**；上限 **RMB 2,000**。标签纸、碳带、运费、税费及澳洲合规电源另计。
- 首年规划假设：首批 119 SKU、706 件；保守规划约 **3,000–5,000 张标签/年**。这是容量规划假设，不是销售预测。
- 标签体系：产品单品、收货/外箱、货位、发货四类标签。
- 客户可见标签：**纯英文**。
- 两年耐久：产品和货位标签采用合成材料、高粘永久胶与树脂碳带，并通过材料文件、加速测试和长期留样共同验证。
- 系统接入：首期由 DriveMate 生成 Code 128/QR 和 PDF/SVG 标签，经 Windows 驱动打印；扫码枪像键盘一样输入现有网页。
- BarTender：可作模板校准和应急打印工具，但不作为核心系统依赖。
- 直接 TSPL 打印、本地打印代理、PWA 相机扫码和离线缓存延后，只有实际运营证据表明确有需要时才开发。

### 1.1 重要边界

- “支持 TSPL/BarTender”不能单独证明设备与 DriveMate 绝对适配，最终以采购验收测试为准。
- Vehicle identity 不等于 parts fitment。标签不得把 VIN/Rego 查询结果直接当作零件适配结论。
- 产品标签不得印未经批准的车型适配、库存、授权、价格或保修承诺。
- 不自行生成或冒用 GS1 GTIN、EAN、UPC、SSCC 或承运商路由条码。
- 当前系统继续保持 `trading=false`、`gst=false`、`mode=pretrade`，除非另有明确授权。

| 项目 | 已批准内容 |

## 3. 硬件采购方案

### 3.1 打印机

**批准型号：TSC TE344**

最低采购要求：

- 300 dpi，4 英寸热转印。
- 最大打印宽度和介质宽度应覆盖 100 mm 标签；接受宽度不低于 108 mm。
- 支持 300 m 碳带。
- 支持间隙、黑标、连续纸，能够执行介质校准。
- USB 接口，Windows 官方驱动。
- TSPL-EZD 或与该具体型号官方资料一致的打印语言。
- 整机、打印头、电源、USB 线及保修条款写入订单。
- 采购目标价：**RMB 1,100–1,350**。该数字是谈价目标，不是已确认报价。

TE344 的 300 dpi 适合较小字号、较密集内容和未来小尺寸标签。对于 70×50 mm 以上的主要标签，长期可扫码仍主要取决于标签材料、碳带、胶黏剂、条码尺寸、静区和打印浓度。

### 3.2 扫码枪

**批准方向：Newland HR22 系列或同级三模二维扫码枪**

最低采购要求：

- 支持 Code 128、QR Code、Data Matrix 及常见一维码。
- 同时具备 2.4G USB 接收器、Bluetooth 和 USB 有线模式。
- 2.4G 模式可作为 USB HID Keyboard 使用，无需专用 SDK。
- 可配置 English keyboard、Enter suffix、蜂鸣和振动提示。
- 有线 USB 能在无线故障时继续扫码并充电。
- 5 米内的五个代表性货架位置均稳定输入。
- 采购目标价：**RMB 350–550**。该数字是谈价目标，不是已确认报价。

离线/库存模式可以选购，但首期必须关闭。网页在收到条码并成功保存后才提示业务成功，避免扫码枪缓存恢复后重复提交。

### 3.3 澳大利亚电源与合规

采购订单必须列出打印机和电源适配器的准确型号。验收时检查：

- 电源输入范围包含澳洲 230 V / 50 Hz 使用条件，通常应标明 `100–240 V~ 50/60 Hz`。
- 输出电压、电流、极性和插头与打印机完全匹配。
- 对澳洲供应或使用的电源安排，取得适用的 RCM、EESS、AS/NZS 或供应商合规证据；仅有 CCC 标志不能代替澳洲适用性核验。
- 插头或电源线应使用符合澳洲要求的 Type I 方案；不把廉价旅行转换头作为长期仓库方案。
- 无法取得中国卖家具体电源的合规证据时，打印机可不随附该电源发运，并在澳洲采购参数完全匹配的合规电源。执行前必须由电气专业人员或设备供应商复核。

参考：[TSC TE Series 官方产品页](https://www.chinatsc.cn/zh-CN/products/te-series-4-inch-desktop-printers)、[Electrical Equipment Safety System：Selling electrical equipment in Australia](https://www.eess.gov.au/equipment/selling-electrical-equipment-in-australia/)。

## 4. 标签纸与碳带采购方案

### 4.1 统一机械规格

向供应商询价和下单时必须写明：

- 打印方式：Thermal Transfer。
- 最大介质宽度：不超过 112 mm。
- 标签卷外径：不超过 127 mm。
- 纸芯内径：25.4–38.1 mm，最终以 TE344 说明书和样机测试为准。
- 标签间隙：建议 3 mm。
- 出纸和卷绕方向：必须与 TE344 传感器及打印面一致。
- 碳带：300 m，适配的纸芯和 ink-side 方向；最终以样机测试确认。
- 碳带宽度应比标签宽 2–5 mm，以保护打印头。

### 4.2 首批耗材建议

| 用途 | 标签规格 | 首批数量 | 碳带建议 |
|---|---|---:|---|
| 产品单品 | 70×50 mm，哑光白色 PP/PET 合成材料，永久高粘丙烯酸胶，3 mm 间隙 | 3,000 张 | 80–85 mm × 300 m 全树脂，2 卷 |
| 收货/外箱 | 100×80 mm，铜版/涂层纸，永久胶；脏污或粗糙表面改用高粘合成材料 | 1,000 张 | 110 mm × 300 m 混合基/蜡树脂，1 卷 |
| 货位 | 100×50 mm，白色 PET/合成材料，永久高粘胶 | 500 张 | 110 mm × 300 m 全树脂，1 卷 |
| 发货 | 100×150 mm A6，永久胶，与承运商格式兼容 | 500 张 | 110 mm × 300 m 混合基/蜡树脂，1 卷 |

批量下单前，先采购每种材料不少于 50 张的样品和对应碳带进行测试。胶水和离型材料存在储存寿命，不建议一次采购数年库存。

### 4.3 澳洲本地补货规格卡

每一种耗材都要保存一张不依赖中国供应商商品名的英文规格卡，至少包含：

- `Label size (W × H)`
- `Gap / black mark`
- `Core ID`、`Maximum roll OD`
- `Winding direction`
- `Face stock material`
- `Permanent high-tack acrylic adhesive`
- `Application temperature` 和 `Service temperature`
- `Ribbon width / length / formulation / ink side`
- 供应商、批号、采购日期和样品测试结果

这样可以在澳洲按通用工业规格补货，无需依赖专有标签卷、RFID 芯片或单一中国卖家。

## 5. 条码规则

### 5.1 业务条码

- 日常仓库业务条码：**Code 128**。
- 条码下方必须保留人眼可读文本。
- 内部 SKU 条码、LPN 条码、Location 条码和 Shipment 条码使用不同前缀空间。
- 推荐前缀示例：
  - 产品：`DMP-GWM-000123`
  - 外箱/LPN：`DMP-LPN-00000421`
  - 货位：`LOC-A-03-02-B`
  - 发货：`DMP-SHP-000123`
- 每个业务标识全局唯一；数据库层保留唯一性约束。
- 条码生成应由 DriveMate 服务器或前端受控模板完成，可使用开源条码库，不需要免费在线网站。

### 5.2 QR Code

产品标签的 QR Code 为可选项，只能链接到长期稳定的 DriveMate 产品或验证页面。目标页面不存在或 URL 尚未冻结时，不打印 QR。

### 5.3 禁止事项

- 未取得 GS1 授权前，不将内部编号表示为 GTIN、EAN、UPC 或 SSCC。
- 不生成承运商路由条码；承运商区域必须使用其正式 PDF、系统或 API 产生的数据。
- 不把 VIN/Rego 识别结果编码为已确认的零件适配关系。

开源生成方案参考：[bwip-js](https://github.com/metafloor/bwip-js)。

| DUR-10 | 两年证据 | 供应商材料寿命声明 + 留样记录共同支撑，不作无证据承诺 |  |

## 8. 仓库业务闭环

```text
Purchase Order
      ↓
Goods Receipt → Count / Batch / Quarantine → Print unit + LPN labels
      ↓
Quality Review → Release or Exception
      ↓
Scan LPN + SKU + Destination Location → Putaway
      ↓
Sales/Trade Order → Pick: Location + SKU + Quantity validation
      ↓
Pack: Item confirmation + Carton/LPN association
      ↓
Carrier label + DriveMate Shipment ID → Dispatch
      ↓
Return/RMA → Quarantine → Inspect → Restock / Reject / Adjust
```

每一步只在服务器确认业务动作成功后更新库存。扫码枪蜂鸣仅代表“读取了条码”，网页成功提示才代表“业务已保存”。

## 9. 系统接入设计

### 9.1 当前可复用能力

现有系统已经具备或已设计：

- 产品 `barcode` 唯一字段。
- 扫码按 SKU、barcode、OEM Part Number 查找。
- 浏览器接收 HID 键盘式扫码和 Enter 触发。
- Purchase Order、Goods Receipt、Quarantine、Batch、Location、Balance、Putaway、Dispatch、RMA 和 Adjustment 等基础领域。

### 9.2 首期打印架构

```text
DriveMate database
        ↓ controlled label data
Next.js label template service
        ↓ SVG/PDF + print job ID
Browser print preview
        ↓ Windows spooler / official driver
TSC TE344 USB printer
```

云端网页不能稳定、通用地直接控制本地 USB 打印机，因此首期采用标准 Windows 打印路径。这样对具体打印机型号依赖最小，也最容易验收和回退。

### 9.3 后期可选本地打印代理

只有首期运营证明需要无弹窗一键打印或高批量自动打印时，才开发本地 Windows 打印代理：

```text
Server print queue → authenticated local agent → TSPL → Windows/USB printer
                         ↑ status / idempotency / retry audit
```

本地代理必须具备设备配对、最小权限、任务幂等、防重复打印、失败重试、状态回传和可撤销队列。不得把 Supabase service role key 或生产 secret 写入浏览器或本地日志。

## 11. BarTender 与自研边界

TSC 驱动、TSPL-EZD 和 BarTender 属于不同层：

- 打印机驱动负责 Windows 与设备通信。
- TSPL 是打印机指令语言。
- BarTender 是标签设计、数据连接和打印管理软件。
- DriveMate 可以自行生成条码、SVG/PDF 和打印任务，达到当前核心业务效果。

因此不需要为首期闭环购买完整仓库系统或强制购买 BarTender。BarTender 可以安装试用或合法授权版本，用于设备校准、供应商模板验证和应急人工打印；仓库库存状态和审计仍以 DriveMate 为唯一业务记录。

## 12. 是否自研或外购

### 当前建议：继续在 DriveMate 内自研轻量仓库闭环

理由：

- 当前 SKU 和标签量较低。
- 现有系统已有产品条码、扫描输入和库存领域基础。
- USB HID 和 Windows 驱动提供低耦合硬件接入。
- 自研可以严格保留“车辆识别、适配证据、库存”三层边界。

### 重新评估外购 WMS 的触发条件

出现以下任意两项并持续发生时，启动 WMS 采购评估：

- 多仓、多班组或多租户运营。
- 日均数百订单、多承运商自动分配和复杂波次拣货。
- 大量序列号、效期、危险品或受监管追溯。
- EDI、大型客户 ASN、SSCC 或零售合规标签成为硬要求。
- 离线移动终端、叉车终端和实时漫游成为核心生产条件。
- 自研维护成本连续两个季度高于成熟 WMS 的总拥有成本。

## 13. 其他软硬件闭环需求

### 首期必需

- Windows 仓库电脑或移动工作台电脑。
- 稳定 Wi-Fi；5 米扫码依赖 2.4G 接收器，不依赖 Wi-Fi。
- 打印机防尘位置、标签卷和碳带干燥储存箱。
- 澳洲合规插座、电源和浪涌保护。
- 电子秤和卷尺，用于发货重量/尺寸。
- 标准包装耗材：纸箱、封箱胶带、缓冲材料、文件袋。
- 货架编码牌或平整标签卡套。
- 收货隔离区、待检区、合格区和退货隔离区的物理标识。

### 后续按业务触发

- 第二台备用扫码枪或充电底座。
- 第二台打印机或备用打印头，不在首年低量阶段提前采购。
- 手持 PDA、手机 PWA 或离线终端。
- 承运商 API、电子秤串口/蓝牙接入。
- 摄像头或照片留档台，用于收货损伤和退货证据。
- UPS，只在本地打印代理或长任务被断电影响时考虑。

## 14. 复核与扩展机制

在以下时间点复核本蓝图：

- 样机和耗材到货验收后。
- 第一批 706 件完成贴标后。
- 正式交易开放前。
- 运营满 3 个月和 6 个月后。
- 任何硬件型号、标签材料、仓库布局或承运商发生变化时。

每次复核记录：实际标签量、打印失败率、扫码失败率、重打率、平均收货/上架/拣货时间、耗材成本、脱胶/糊码投诉和异常库存事件。
