# 标签用途与现有能力

本轮版本：标签 v4 集成。2026-09-07 已单独完成 Production v23 与 119 条资料回填，页面/打印组件尚未发布至 Production。执行事实见 [v23 生产执行报告](../qa/2026-09-07-v23-production-execution.md)。

| 标签 | 本轮实现 | 用途及准确性规则 |
|---|---|---|
| Product / 70 × 50 mm | 共用预览与打印组件；新任务冻结 v4 内容；旧任务使用旧版 | 保留供应商包装，加贴 DriveMate 补充标签。For 表示适用品牌，不表示制造商。Position 不适用时不输出，未确认时提示补资料。 |
| Location / 100 × 50 mm | 共用预览与打印组件；完整库位编码、DMLOC 条码及扫描用途 | 固定库位身份，不能表示产品、库存数量、收货或已打印状态。不根据分隔符猜测实际货架位置。 |
| Receiving carton / 100 × 80 mm | 校正模板字段定义，尚无可操作打印链路 | 区分来源箱组与实体箱；只标预期内容，不把预期数量写成实收数量；无实体箱映射时不编造成员箱明细。 |
| Dispatch / 100 × 150 mm | 校正模板字段定义，尚无可操作打印链路 | 出库时才能绑定客户、地址、订单及包裹序号。内部 shipment ID 不能冒充承运商 tracking number。 |

箱标与配送标签需要后续独立的业务流程设计才能启用。本轮没有增加虚假按钮、承运商接口、通用模板编辑器或收货确认绕行路径。

## 产品资料维护

在 `/admin` 的 SKU master data 选择产品，填写 Supplementary product label 区域，随后 Save SKU master。

- 英文名称、适用品牌（逗号分隔）、中性 Part reference、Position applicability。
- 未核实的位置选 Not yet confirmed。无位置属性的产品经确认后选 Not applicable。
- 可以保留未完成资料；无效格式（如空的指定位置、重复品牌、非法字符）需先纠正。
- 宽度超限需使用经核实的简短文字，系统不截断、不自行缩小字号或编造内容。
- 后续修改只影响新任务。重印沿用原任务快照，包含其原版样式和文字。
- 新建 SKU 后可在同一编辑区补充标签资料。批量导入不覆盖已有 labelProfile。
