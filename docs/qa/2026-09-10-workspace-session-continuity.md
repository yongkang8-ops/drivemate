## 本轮边界

针对用户截图中的登录闪现、同一账号跨页主导航跳位进行有界修复。保留管理中心二级菜单、业务组件、原路径、深链接返回、整页导航的未保存内容保护、服务端权限及按需 MFA。无 Production 操作。

## 已定位原因及修复

- AuthPanel 在会话尚未确认时以 profile=null 渲染登录表单；RoleGate 同时显示需要登录。增加 checking/resolved/unavailable 阶段，检查中不渲染登录或受保护内容，服务异常提供显式重试。
- 公共页头此前直到 has-access 才隐藏，内部跨页会短暂出现官网外壳。内部待检查阶段使用中性工作区背景；明确未登录后仍可登录。
- 六个内部页面各有品牌块与导航样式。统一 WorkspaceBrand 及主导航排版；管理分区保留，账户角色仍从已验证会话获得。原版 admin→partner 首链接 Y 位置相差约 109px，新增几何测试捕捉该问题。
- 保留既有 pagehide 清除受保护内容和密码、pageshow 重新验证机制；不缓存密码或信任过期身份。
- 无 JavaScript 时提供开启 JavaScript 的明确说明。
